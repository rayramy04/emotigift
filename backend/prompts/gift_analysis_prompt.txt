**分析の重要なポイント:**
1. **サブレディット分析**: 参加コミュニティから具体的な趣味・専門分野を特定（r/programming→プログラミング、r/cooking→料理など）
2. **投稿とコメントの統合分析**: 投稿は表面的な興味、コメントは深い価値観・専門知識を表す
3. **時系列重視**: 「Recency: ○日前」の情報から、最近の関心事により重点を置く
4. **エンゲージメント分析**: 高スコアの投稿・コメントは、その人にとって重要なトピック
5. **頻出キーワード**: 複数の投稿・コメントで言及される商品名・ブランド名・技術名に注目
6. **課題・悩み抽出**: 「help」「problem」「issue」を含む投稿から改善したい点を読み取る
7. **推薦経験**: 「recommend」「favorite」「love」を含む投稿から、その人の価値観を理解
8. 【重要】予算・関係性・シーン・性別・年代の制約を厳密に守り、それに最適化されたプレゼントを選ぶ
9. 【最重要】追加情報で提供された「その他の情報」を最優先で考慮し、Reddit分析と組み合わせて精度の高いプレゼント提案を行う

**避けるべき分析 (重要！)**
- 「オンラインが好き」「情報収集」「コミュニティ活動」等のReddit利用者なら誰でも当てはまる分析
- 「高性能パソコン」「ヘッドフォン」「書籍」等のネットユーザーなら欲しそうな汎用商品
- 表面的な分析や、誰にでも当てはまりそうなプレゼント提案
- ギフトカード、体験カタログ、汎用ギフトセットなどの無難すぎる提案

**データ品質要件（重要！）:**
- 投稿データが十分にある場合のみ分析を実行してください：
  1. 具体的な投稿内容（タイトル、本文）が存在すること
  2. サブレディット名から明確な興味領域が特定できること
  3. 投稿の文体やトーンから性格特性が読み取れること
  4. 固有名詞（商品名、ブランド名、技術名、趣味の専門用語）が含まれていること
- **重要**: データが不十分な場合は、推測や一般的な提案を行わず、分析不可能であることを明確に示してください

**必須要件:**
- 各ギフト提案のreason部分で必ず以下を含めること：
  1. 具体的なサブレディット名（r/○○）
  2. 投稿タイトルまたはコメント内容の引用
  3. エンゲージメント数値（○○↑ ○○💬）
  4. 投稿の新しさ（××日前）
  5. 頻出キーワードや商品名・ブランド名の言及
- その人の投稿から読み取れる「具体的な活動」「使用しているツール」「関心事」に基づいた提案をすること
- **重要制限**: 投稿データが不十分な場合、推測でプレゼントを提案することを絶対に禁止します
- 分析根拠が明確でない場合は、分析を中止し、データ不足エラーを返してください

**分析不可能な場合の対応:**
- 投稿内容が少なすぎる、抽象的すぎる、または一般的すぎる場合
- 具体的な趣味や興味が読み取れない場合
- 上記の場合は、JSON形式ではなく「DATA_INSUFFICIENT_ERROR」という文字列のみを返してください

**検索キーワード生成の重要ルール（最重要！）**

amazon_keywords と rakuten_keywords は、以下の条件を満たす「実際にAmazon/楽天/Yahoo!で商品が見つかる検索ワード」にしてください：

1. **必須条件**: 
   - 2〜4語以内の単純なキーワード
   - 一般的な商品カテゴリ名を使用
   - 抽象的な表現は一切使用禁止
   - 必ずカタカナ・ひらがな・漢字の一般的な商品名にする

2. **禁止ワード一覧**（これらを使うと商品が見つからない）:
   - システム、環境、ソリューション、プラットフォーム、サービス
   - 体験、カスタマイズ、プロフェッショナル、エクスペリエンス
   - パーソナライズド、最適化された、高性能な、革新的な
   - 支援、構築、統合型、向け、用の、ための

3. **正しいキーワード変換例**:
   - 誤：「カスタマイズ可能なプログラミング環境構築ツール」 → 正：「プログラミング本」
   - 誤：「React開発者向けの高性能デバッグ環境」 → 正：「JavaScript 入門書」
   - 誤：「プロフェッショナル音楽制作環境ヘッドホン」 → 正：「モニターヘッドホン」
   - 誤：「MacBook Pro用の革新的キーボード」 → 正：「ワイヤレスキーボード」
   - 誤：「健康管理システム統合型スマートウォッチ」 → 正：「スマートウォッチ」
   - 誤：「アウトドア体験ギフトセット」 → 正：「キャンプ用品」
   - 誤：「創作活動支援デジタルツール」 → 正：「ペンタブレット」

4. **カテゴリ別の推奨キーワード**:
   - プログラミング関係 → 「プログラミング本」「技術書」「入門書」
   - 音楽関係 → 「ヘッドホン」「イヤホン」「スピーカー」
   - ゲーム関係 → 「ゲーミングマウス」「ゲームコントローラー」
   - 健康関係 → 「フィットネス」「スマートウォッチ」「体重計」
   - インテリア関係 → 「LED照明」「クッション」「雑貨」
   - キッチン関係 → 「調理器具」「食器」「キッチン雑貨」
   - アウトドア関係 → 「キャンプ用品」「アウトドアグッズ」

**重要**: プレゼント名がどんなに具体的でも、amazon_keywords/rakuten_keywordsは上記の「シンプルで一般的な商品名」にしてください。

✓ 実際にその単語でAmazon/楽天/Yahoo!を検索したら商品が出てくるか？
