**避けるべき分析 (重要！)**
- 「チャットをよく使う」「コミュニケーション好き」等のチャット利用者なら誰でも当てはまる分析
- 表面的な分析や、誰にでも当てはまりそうなプレゼント提案
- ギフトカード、体験カタログ、汎用ギフトセットなどの無難すぎる提案

**データ品質要件（重要！）:**
- チャット内容が十分にある場合のみ分析を実行してください：
  1. 具体的な会話内容が存在すること
  2. その人の興味や関心が読み取れる発言があること
  3. 会話の文体やトーンから性格特性が読み取れること
  4. 固有名詞（商品名、ブランド名、場所名、活動名）が含まれていること
- **重要**: データが不十分な場合は、推測や一般的な提案を行わず、分析不可能であることを明確に示してください

**必須要件:**
- 各ギフト提案のreason部分で必ず以下を含めること：
  1. 具体的な会話内容の引用
  2. その人の発言から読み取れる興味・関心・課題
  3. 頻出する話題や言及されるものの名前
  4. 最近の会話内容への言及
  5. その人の価値観や性格が表れる発言の分析
- その人の会話から読み取れる「具体的な活動」「使用しているもの」「関心事」に基づいた提案をすること
- **重要制限**: チャット内容が不十分な場合、推測でプレゼントを提案することを絶対に禁止します
- 分析根拠が明確でない場合は、分析を中止し、データ不足エラーを返してください

**分析不可能な場合の対応:**
- 会話内容が少なすぎる、抽象的すぎる、または一般的すぎる場合
- 具体的な趣味や興味が読み取れない場合
- 上記の場合は、JSON形式ではなく「DATA_INSUFFICIENT_ERROR」という文字列のみを返してください

**検索キーワード生成の重要ルール（最重要！）**

amazon_keywords と rakuten_keywords は、以下の条件を満たす「実際にAmazon/楽天で商品が見つかる検索ワード」にしてください：

1. **必須条件**: 
   - 2〜4語以内の単純なキーワード
   - 一般的な商品カテゴリ名を使用
   - 抽象的な表現は一切使用禁止
   - 必ずカタカナ・ひらがな・漢字の一般的な商品名にする

2. **禁止ワード一覧**（これらを使うと商品が見つからない）:
   - システム、環境、ソリューション、プラットフォーム、サービス
   - 体験、カスタマイズ、プロフェッショナル、エクスペリエンス
   - パーソナライズド、最適化された、高性能な、革新的な
   - 支援、構築、統合型、向け、用の、ための

3. **正しいキーワード変換例**:
   - 誤：「カスタマイズ可能なプログラミング環境構築ツール」 → 正：「プログラミング本」
   - 誤：「React開発者向けの高性能デバッグ環境」 → 正：「JavaScript 入門書」
   - 誤：「プロフェッショナル音楽制作環境ヘッドホン」 → 正：「モニターヘッドホン」
   - 誤：「MacBook Pro用の革新的キーボード」 → 正：「ワイヤレスキーボード」
   - 誤：「健康管理システム統合型スマートウォッチ」 → 正：「スマートウォッチ」
   - 誤：「アウトドア体験ギフトセット」 → 正：「キャンプ用品」
   - 誤：「創作活動支援デジタルツール」 → 正：「ペンタブレット」

4. **カテゴリ別の推奨キーワード**:
   - プログラミング関係 → 「プログラミング本」「技術書」「入門書」
   - 音楽関係 → 「ヘッドホン」「イヤホン」「スピーカー」
   - ゲーム関係 → 「ゲーミングマウス」「ゲームコントローラー」
